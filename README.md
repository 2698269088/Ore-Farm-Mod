# Ore Farm Mod (OreFarm)

> 一个 Minecraft **1.12.2 / Forge** 模组：像种西瓜南瓜一样，把「矿石种子」种在耕地上，成熟后藤蔓旁会长出对应的**矿石方块**。内置 7 种原版矿石，并可与 **工业时代2 (IC2)** 联动种出铜/锡/铅/铀。

- **种矿如种瓜**：种子种在耕地上，随随机刻生长（0~7 级），成熟后在相邻的空地生成对应矿石方块，就像西瓜/南瓜长在藤旁。
- **7 种原版矿石**：煤、铁、金、钻石、绿宝石、青金石、红石。
- **成熟藤蔓会拐弯**：成熟且某侧长出本茎的矿石时，藤蔓朝向该矿石（`getActualState` + multipart 状态）。
- **IC2 联动（软依赖）**：装了 IC2 时额外提供铜 / 锡 / 铅 / 铀 四种矿石种子；未装 IC2 时自动隐藏、不报错。
